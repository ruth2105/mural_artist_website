## 📝 DRAFT → PUBLISHED WORKFLOW

```
┌─────────────────────────────────────────────────────────────┐
│  SCENARIO: Add multiple projects quickly                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  SESSION 1: QUICK UPLOAD (10 minutes)                       │
│                                                             │
│  For each project:                                          │
│  1. Add artwork                                             │
│  2. Upload image                                            │
│  3. Add title + category                                    │

│  5. Save                                                    │

└─────────────────────────────────────────────────────────────┘
                              │
                              ▼

│  2. Edit project                                            │
│  3. Add description                                         │
│  4. Add video link                                          │
│  5. Add year, location                                      │
│  6. Status: PUBLISHED                                       │
│  7. Update                                                  │
│                                                             │
│  Result: 5 projects live on website!                        │
└─────────────────────────────────────────────────────────────┘
```
